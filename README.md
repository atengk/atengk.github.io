## 🛠️ 本地开发与构建

本站基于 [VitePress](https://vitepress.dev/) 静态站点生成器构建。

```bash
# 1. 克隆代码仓库
git clone https://github.com/atengk/atengk.github.io.git
cd atengk.github.io

# 2. 启动本地开发服务 (支持实时热更新)
npx vitepress dev

# 3. 执行全量静态打包构建
npx vitepress build

# 4. 本地预览打包产物
npx vitepress preview
```
